CLI Adivina mi número
---

Proyecto creado como uno de los retos de Roadmap.sh

Aplicación de consola diseñada con .NET 10 para resolver el reto de roadmap.sh "[Number Guessing Game](https://roadmap.sh/projects/number-guessing-game)".

Características
---

*   Selección de dificultad.
*   Validación de entrada.
*   Entrada/Salida de consola.
*   Lógica de flujo de juego

Instalación
---

1.  Clona el repositorio
    
```bash
git clone https://github.com/juanharodev/juanharodev.github.io.git
```
---

2.  Abre la una terminal y navega hasta la carpeta del proyecto
    
```bash
cd /portfolio/roadmap-sh/backend/04-number-guessing-game
```
---
3.  Restaura las dependencias del proyecto
    
```bash
dotnet restore
```    
---

4. Compila el proyecto 
```bash
dotnet build
```    

5.  Corre la aplicación y sigue las instrucciones de juego
```bash    
dotnet run
```    

¿Cómo se usa?
---

Una vez instalado usa el comando _dotnet run_ para iniciar el juego.

### Ejemplo de uso
```bash
dotnet run
```
